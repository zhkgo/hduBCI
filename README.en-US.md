

# hduBCI
hduBCI for device, algorithm, and application connection.

Hangzhou Dianzi University, 515 Brain-Computer Collaborative Intelligence Laboratory.

Currently supports connectivity with neuroscan devices, BoRuiKang DSI-24, and extended EEG caps.
